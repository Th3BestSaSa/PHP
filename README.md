# PHP Examples 🚀

Repositorio con ejemplos y pruebas en **PHP** para aprender y experimentar con el lenguaje.

## 📌 Descripción
Este repositorio contiene scripts y ejemplos escritos en PHP.  
Está pensado para practicar programación backend, aprender sintaxis del lenguaje y probar funcionalidades básicas del desarrollo web.

PHP es un lenguaje de programación ampliamente usado para desarrollo web del lado del servidor y permite generar páginas dinámicas y aplicaciones web. :contentReference[oaicite:1]{index=1}

## ⚙️ Requisitos

Para ejecutar los archivos necesitas:

- PHP 7 o superior
- Servidor web (Apache / Nginx) o servidor local
- Navegador web

Usado:
- XAMPP
- Visual Studio Code
